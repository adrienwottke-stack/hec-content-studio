    EINMAL VERBINDEN

    Automatisch gute Momente finden.

    Die Videoanalyse nutzt Gemini von Google. Der Schlüssel wird auf deinem Server gespeichert und danach nicht mehr im Browser angezeigt.

    Bei einem KI-Schnitt werden komprimierte Kopien deiner Aufnahmen an Google übertragen. Die temporären Anbieterdateien werden nach dem Auftrag zum Löschen angefordert. API-Nutzung wird über dein Google-Konto abgerechnet.

    DEIN CODEX-BRAIN

    Aufnahmen rein.
    Ideen zurück.

    Der Agent in deinem Codex-Chat bewertet eure Aufnahmen, ergänzt passende Verwendung und Reel-Ideen und plant die Schnitte. Dein Server erstellt daraus die fertigen Reels.

    Die Automation prüft alle zehn Minuten auf neue Aufträge. Dafür müssen dein Rechner und Codex laufen. Während Codex offline ist, bleiben Uploads gespeichert und Aufträge warten. Es ist kein Gemini- oder separater OpenAI-API-Schlüssel nötig.
